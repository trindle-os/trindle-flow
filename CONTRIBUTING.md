# Contributing

Thank you for taking an interest in Flow. It is appreciated.

The way this project is set up, the code is written and kept in one place, so code changes from outside cannot be taken. That has nothing to do with the quality of anyone's work. It works best when we hear what went wrong and fix it ourselves.

So the most useful thing you can send is a description. Report bugs and ask questions on the [Buildmorphic community](https://buildmorphic.com); [GitHub issues](https://github.com/trindle-os/trindle-flow/issues) are also welcome.

- **Something broken?** Say what you did, what you expected, and what happened instead. The Flow version (`flow version`), the Trindle version on both computers, which one controls, and how they are connected (the same network, Wi-Fi, Tailscale) help a great deal. What `flow tell` says on each computer is welcome too.
- **An idea?** Say what you were trying to do and where Flow got in the way. You do not need to suggest the fix.
- **A security problem?** Please use private reporting rather than a public issue. [SECURITY.md](SECURITY.md) explains how.

Flow is under the GNU General Public License, so you are always free to fork it and take it in your own direction.
